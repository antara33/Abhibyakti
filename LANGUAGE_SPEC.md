# Bhasha Programming Language Specification

## 1. Overview

Bhasha is a simple Bangla-based programming language developed
for our Compiler Design project.

## 2. Data Types

The language supports the following data types:

1. সংখ্যা - Integer
2. দশমিক - Decimal
3. লেখা - String
4. চরিত্র - Character
5. সত্যমিথ্যা - Boolean
6. তালিকা - List/Array
7. দীর্ঘসংখ্যা - Long Integer
8. ধনাত্মক - Non-negative Integer
9. শূন্য - Void

## 3. Variable Declaration

সংখ্যা x = 10;

দশমিক pi = 3.14;

লেখা নাম = "Antara";

চরিত্র grade = 'A';

সত্যমিথ্যা pass = সত্য;

## 4. Assignment

x = 20;
